📝 To-Do App (Full Stack)

A full-stack To-Do application to manage daily tasks with CRUD operations, built using React, Node.js, and MySQL.

🚀 Features
Add, edit, delete tasks
Mark as completed/pending
Search & filter tasks
Dark/Light mode
Timestamp for each task

🛠️ Tech Stack

Frontend: React.js, HTML, CSS, JavaScript
Backend: Node.js, Express.js
Database: MySQL


Backend

cd backend
npm install
npm start

Frontend

cd frontend
npm install
npm start
🔗 API
GET /api/todos
POST /api/todos
PUT /api/todos/:id
DELETE /api/todos/:id
